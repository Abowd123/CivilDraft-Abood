# عُدّة فحص الواجهة التعليمية في المتصفح

## الآلي (Chromium عبر Playwright)
```
python3 -m http.server 8765            # من جذر المشروع
node docs/learn/smoke-phase8.mjs       # الخريطة · البحث · البطاقات · الشهادة
```
السكربت يطبع النتائج ويحفظ لقطات `p8_*.png`. عدّل مسار `executablePath` إلى متصفّحك.

## اليدوي (١٠ دقائق — حاسوب ثم جوال)
| # | الخطوة | المتوقَّع |
|---|---|---|
| ١ | زرّ القبّعة في الوصول السريع | الخريطة: ٧ محطّات + «بطاقات الأدوات» + الإحصاءات |
| ٢ | «أوّل غرفة» من البداية بالفأرة | الشبح على النقطة، الإضاءة على الزرّ، المدرّب لا يغطّي سطر الأوامر |
| ٣ | انتظر ٨ ث ثم ١٨ ث بلا حركة | التلميح ثم زرّ «شاهدني» |
| ٤ | «شاهدني» | مؤشّرٌ ينزلق وينقر، والخطوة تتمّ |
| ٥ | «إنهاء» وسط الدرس | يرجع مشروعك حرفاً، والتراجع يعمل عليه |
| ٦ | أغلق التبويب وسط الدرس ثم افتحه | مشروعك كما كان قبل الدرس (الحفظ معلَّق أثناءه) |
| ٧ | «طابقٌ ثانٍ» و«المجسّم الثلاثي» | الإضاءة داخل النوافذ والمدرّب فوقها |
| ٨ | ابحث «باب» ثم Esc | نتائج فورية، وEsc يمسح البحث ثم يغلق |
| ٩ | الأسهم ↑↓ في الخريطة | التنقّل بين المحطّات والدروس |
| ١٠ | بطاقة أداة (مثلاً «قياس») | اضغط ← جرّب ← Esc ← «جرّبتَ» |
| ١١ | الفيلا حتى النهاية ثم «نزّل الفيلا ملفّاً» | ملف المشروع يُنزَّل |
| ١٢ | «شهادتك» ← اسمك ← أنشئ ← نزّل | SVG A4 بالاسم والشعار والتاريخ بالكلمات |
| ١٣ | كرّر ٢ على الجوال (< ٦٤٠px) | المدرّب شريطٌ رفيعٌ أعلى الشاشة |
| ١٤ | السمة الفاتحة | الألوان مقروءة في الخريطة والمدرّب |
| ١٥ | «تقليل الحركة» في النظام | لا انزلاق ولا نبض |
