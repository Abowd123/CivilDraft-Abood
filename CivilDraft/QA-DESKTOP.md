# قائمة الاختبار اليدوي — CivilDraft لسطح المكتب (ويندوز)

يُكمِل هذا الملفُّ اختباراتِ Playwright الآلية (`npm run test:e2e`، مجلّد `desktop/e2e`). الآلية تغطّي: ظهور النافذة، Ctrl+S وCtrl+O، حفظ `.cdraft` وفتحه، بقاء البيانات، ومنع النسخة الثانية. وهي تستبدل نافذة «فتح» الأصلية بمسارٍ جاهز (`stubOpenDialog`)، وتغلق شاشة الترحيب والجولة، وترسم الجدران عبر سطر الأوامر لا بالفأرة. **هنا ما لا يُختبر آلياً**: الحوارات الأصلية في ويندوز (ومنها نافذة «فتح»)، الرسم بالفأرة، الشاشات عالية الدقّة، البرامج الخارجية (AutoCAD وExcel وOllama)، انقطاع الإنترنت، واختلاف ويندوز 10 عن 11.

**كيف تستعمله:** لكل بند: خطواتٌ ← نتيجةٌ متوقّعة ← خانة النتيجة. علّم `✓` عند التطابق التامّ، و`✗` عند أي اختلاف مع كتابة ما رأيت في «ملاحظات» (ولقطة شاشة إن أمكن).

### تجهيزات قبل البدء
1. ثبّت من ملفّ `CivilDraft-Setup-<الإصدار>.exe` الناتج عن `npm run dist:win` (لا من `npm run desktop`) — الاختبار على ما يُسلَّم للمستخدم فعلاً.
2. استعمل **حساب مستخدم نظيفاً** أو احذف `%APPDATA%\CivilDraft` قبل «أول تشغيل».
3. جهّز ملفّات: `sample-simple.dxf` (جدران وفتحات ونصوص عربية)، `sample-heavy.dxf` (أكثر من 20 ألف كيان)، `sample-cp1256.dxf` (ترميز CP1256)، `bad.dxf` (ملفّ مقطوع)، و`plan.cdraft` (مشروعٌ بطابقَين وفتحات وأعمدة).
4. ثبّت Excel أو LibreOffice، وبرنامج DXF خارجياً (AutoCAD أو LibreCAD أو DWG TrueView).

### 2.7 «فتح» بنقر الفأرة على القائمة

**الخطوات:** 1) احفظ مشروعاً `.cdraft` ثم افتح برنامجاً بمشروعٍ فارغ · 2) **بالفأرة فقط** (بلا لوحة مفاتيح): «ملف ◂ فتح ملفّ المشروع…» · 3) اختر الملفّ · 4) كرّر من «ملف ◂ فتح…» مرّةً ثانية واضغط «إلغاء» · 5) كرّر والمشروع فيه رسمٌ غير محفوظ.
**المتوقع:** تظهر نافذة اختيار الملفّ الأصلية فوراً بعنوان «فتح»، وتعرض `.cdraft` و`.json` و`.mistar` مع «كل الملفات»؛ بعد الاختيار يظهر في السجلّ «فُتح <الاسم> · N جدار …» بالعدد المحفوظ؛ الإلغاء لا يغيّر شيئاً ولا يُبلغ عن خطأ؛ في (5) يظهر تأكيد «سيُفقد غير المحفوظ» قبل الاستبدال.
