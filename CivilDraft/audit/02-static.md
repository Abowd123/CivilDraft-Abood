### CSP

النسخ الثلاث متكافئة دلالياً في التوجيهات: `index.html:25-34`، `netlify.toml:7`، `_headers:2` تحتوي جميعاً `default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self' data: blob:; connect-src 'self' https: http://localhost:* http://127.0.0.1:*; object-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'`. اختلافها الوحيد تغليف HTML/TOML/headers، لا قيمة التوجيه.

المسح الثابت وجد: لا `style=` أو `<style>` أو `setAttribute("style")` أو `style.cssText`، ولا سمة حدث HTML، ولا `javascript:` تنفيذي، ولا إنشاء `script/style/link`، ولا `document.styleSheets`/`insertRule`/`replaceSync`، ولا `Worker`/`SharedWorker`/`blob:` أو `data:` script/worker. `Blob` و`URL.createObjectURL` في التصدير والتنزيل فقط؛ و`img-src data: blob:` يسمحان بهما، وطلبات AI تمر بـ`validateUrl()` في `js/ai/net.js:101-123` ثم يحدها CSP إلى HTTPS أو المضيفين المحليين HTTP. لا يوجد خرق CSP فعلي ثابتياً.

اختبار CSP الموجود يفحص فقط خمسة أشكال (HTML `style=`, `<style>`, `setAttribute(style)`, `style.cssText` وقالب HTML)، ولا يختبر inline event attributes أو `javascript:` أو script/style/link ديناميكي أو worker/blob/data أو `img/connect`. الفحص اليدوي أعلاه عوّض الغياب، لكن الاختبار نفسه ليس guard كاملاً (P2-006).

الحدود المقروءة: project file `24 MiB` (`io/project.js:177`)، AI URL 300/key 500/response 1 MiB/image 4 MiB (`ai/net.js:8,23-29,77-81,226-229`)، macros 50×400×200 (`core/macros.js:14`)، journal 4000/taint 200، history 100، snapshots 12، views/workspaces 24، reference entities/points من `core/limits.js`. لا حدّ إجمالي localStorage (يعتمد على المتصفح). `io/store` عند quota يحاول full ثم lite بلا المرجع ثم يعيد failure؛ state يعرضه عبر `ONSAVE`. بقية writers الصامتة هي P2-005.

### API key

المفتاح في `localStorage` تحت `civildraft.ai` فقط إذا `AI.keep`، وإلا `saveAI()` يكتب `key:""` (`js/ai/net.js:69-90`). في DOM يعرض ثماني نقاط (`js/ui/ai.js:311-314`)، ولا يدخل `pack()/toJSON()` أو DXF/PDF/SVG/JSON/project save/journal/macros؛ البحث الثابت لا يجد share-link أو URL parameter أو `console.log(AI.key)`. الطلب الوحيد هو `fetch(AI.url)` في `js/ai/net.js:196-201` مع `Authorization: Bearer`; العنوان يُتحقق من http/https بلا credentials، وCSP يمنع external HTTP غير المحلي. المستخدم يستطيع اختيار HTTPS origin مخصصاً بيده؛ ليس تسريباً خفياً، لكن لا توجد allowlist لخدمات HTTPS المخصصة. رد الخطأ يضم أول 180 محرفاً من body (`:220-221,280-281`) ولا يضم المفتاح صراحةً؛ مزود خبيث يستطيع نظرياً إعادة نص حساس في body، لكنه لا يثبت تسريب المفتاح نفسه.

### Shared mutable state

المالك القانوني للحالة هو `S` في `core/state.js`، لكن أدوات وواجهات كثيرة تستوردها وتعدّل مصفوفاتها مباشرةً داخل `edit()`. `UIS` في `ui/store.js` مشترك بين dock/cmdline/statusbar/ribbon، و`AI` بين `ai/net.js` و`ui/ai.js`، و`SNAP.list` محصور فعلياً في `io/snaps.js`. لا يوجد مفتاح واحد يكتبه مساران غير مقصودين بعد تتبع الاستيراد؛ الكتابات المقصودة تمر عبر `edit`/`uiSet`/`saveAI`. الاستثناءان الفعليان هما race اللقطات (P2-003) وversion corruption (P2-004). autosave في `state.js:1474-1530` لديه `DIRTY/BUSY/SEALED` و`saveNow` يمنع كتابة snapshot أقدم بعد الإغلاق؛ `io/store.js:202-218,278-299` fallback مضبوط، لذلك لم أبلغ race autosave نفسه.

## ملاحظات إيجابية/false positives

- `innerHTML` في `helpbot.js:148` ثابت (`<span>` ثلاث مرات)، وليس رد AI؛ الرد نفسه `textContent`.
- `Blob` و`createObjectURL` في `io/project.js`, `io/report.js`, `io/boqcsv.js`, `io/export.js` تنزيلات، لا script/worker.
- تعيينات `.onclick = fn` في guide/AI هي خصائص DOM لا inline event-handler attributes في HTML، ولا يوجد `onclick="..."` أو `javascript:` URL.
- `.style.property=` وCSSOM `style.background` مستعملان للحركة/الأبعاد/ألوان الطبقات؛ guard الحالي يستثني property assignment صراحةً، ولا يوجد `cssText` أو style string. لم أعتبرها خرق CSP وفق قاعدة المشروع الموثقة في `bootguard.js:6-11`.

## لم يُفحص

- لم يُجرَ اختبار runtime في متصفّح، وفق قاعدة `.context.md`؛ لذلك لم أتحقق تجريبياً من رسائل quota أو سلوك CSP الفعلي في محرك معين، واكتفيت بمسارات الشيفرة الثابتة.
- لم أُنشئ DXF/JSON/AI response فعلياً لتشغيل كل مسار؛ تتبعت المصدر إلى sink وقرأت validators/escapers ذات الصلة. لا توجد ملفات خارج population أعلاه أو أسرار تشغيلية متاحة للفحص.
